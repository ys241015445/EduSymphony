# 字段映射与填写顺序

## 总顺序

1. 人培对齐  
2. 教学大纲  
3. **询问上课时间（门禁）**  
4. 教学日历 xlsx  
5. 教案  
6. 可选 PPT/思路图  

## 教学大纲（附件3 / 附件4）

复制模版后按模版原有章节顺序填写，常见块：

1. 封面/基本信息：课程名称、代码、学分、学时、学院、适用专业、先修课等  
2. 课程简介  
3. 课程目标（与人培毕业要求/目标表述对齐）  
4. 教学内容与学时分配（理论章节；有实验则含实验项目表）  
5. 教学方法与手段（保留模版体例；可按课微调 Python/工具名等）  
6. 考核与评价（成绩构成表；有表2 达成度则按规范填权重）  
7. 教材与参考资料  
8. 其它模版固有栏（审核签字等）— 无信息则留空，不删行  

**学时**：总学时 = 理论 + 实验；与人培或用户截图一致。  

**格式**：只改 `Range.Text` / 单元格文本；勿重设整节样式。

## 上课时间门禁（问清再往下）

向用户收集，可多条：

```text
理论：周X 第A–B节；教室：…
实验：周Y 第C–D节；教室：…（若无实验则省略）
```

写入日历对应列；教案「授课时间」行引用同一信息。

## 教学日历（xlsx）

以样例文件为壳 `copy` 后改：

- 表头元数据：课码、课名、性质、学院、班级、考核、周数、总/理论/实验学时、人数  
- 周次行：第 N 周教学内容摘要（来自大纲/进度）  
- 上课时间列：门禁确认结果  
- **图片/附图区域**：保留结构；内容留给用户；可在备注写「插图由教师自行粘贴」  

有实验学时则同时产出理论 + 实验两份日历。

## 教案（教学设计）

以「参考模版」为壳；每一课次一张表（或模版规定结构），字段通常包括：

| 行/区 | 来源 |
|---|---|
| 授课题目 | 日历该格主题 |
| 授课时间 / 学时 | 日历 + 门禁时间 |
| 学情分析 | 按专业年级撰写，勿套错专业 |
| 教学目标 | 思政/知识/能力/素质，对齐大纲目标 |
| 主要教学内容 | 进度表/日历要点 |
| 重点难点 | 本课 2–4 条 |
| 教学方法 / 媒体 | 勾选或沿模版，工具写本课 IDE |
| 教学过程设计 | **详略见 quality-bar.md** |
| 复习作业 | 可执行、可检查 |
| 参考资料 | 教材 + 本课资料/PPT |
| 评估反馈 | 课堂/作业/实验 |

课次数量与顺序 = 教学日历有效教学格（理论+实验分别计入）。

## 可选增强

- PPT/讲义路径 → 按文件名或用户说明映射到周次 → 写入该课「参考资料」或过程演示段  
- 思路图：matplotlib 等自绘，插入过程设计单元格；避免无意义的整页课件截图
