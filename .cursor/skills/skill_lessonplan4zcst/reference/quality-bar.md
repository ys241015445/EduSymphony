# 教案详略质量条（对齐大模型样板）

对照样板：`大模型全栈应用开发-教学设计（教案）.doc`（路径见 defaults.md）。  
检查的是**颗粒度与结构**，不是照搬该课技术内容。

## 教学过程设计（每课必备结构）

至少包含分时段小节：

1. **导入**（约 5–10 分钟）：问题/场景引出本课目标  
2. **新知精讲**：对应进度要点分条，含易错点  
3. **演示操作**：本课工具逐步演示（非空话）  
4. **随堂练习 / 实战**：学生任务 + 教师巡视要点  
5. **小结与布置**：回顾 + 可检查的作业  

6 学时或连续主题：可分「第 1/2/3 段」写清时间块，仍保持上述要素。

## 长度与可读性

- 2 学时：过程设计应明显长于「一句话带过」；建议含具体步骤与时间标注。  
- 禁止整段只有「讲授法、练习法相结合」而无步骤。  
- 用语与本课一致（工具、库、平台）；禁止残留其它课程技术栈名称。

## 配图

- 优先：**思路图 / 流程图 / 框架图**（自绘）。  
- 用户指定 PPT 页时可截关键页；禁止无说明的大段课件墙。  
- 不要写「课件配图」占位而不附图。

## 与日历一致性

- 授课题目、周次、学时与日历对应格一致。  
- 实验课过程以任务驱动与提交要求为主，仍要有说明–思路–实作–点评结构。

## 交前抽查（任抽 2 课）

- [ ] 有导入/精讲/演示/练习/小结  
- [ ] 有时间分配或清晰段落  
- [ ] 内容来自大纲/日历，非空洞套话  
- [ ] 第 1–2 页封面未被改乱  
- [ ] 至少理论课有合理配图或明确无图理由（习题/纯考试可仅知识结构图）
