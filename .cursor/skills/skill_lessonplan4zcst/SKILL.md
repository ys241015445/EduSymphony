# 珠科教学材料自动化（skill_lessonplan4zcst）

按固定流水线生成珠科教学材料。先读本文件；路径、字段与 DeepSeek 约定见 `reference/`。

## 分工（硬约束）

| 角色 | 职责 |
|---|---|
| **DeepSeek** | 生成**全部教学正文**：课程目标与章节、学时切分、进度/日历周次教学内容、教案各字段长文 |
| **Cursor Agent（本 Skill）** | 模式判定、人培/模版路径、上课时间门禁、复制模版、把 DeepSeek 的结构化 JSON **写入** Word/Excel（只改内容不改排版）、可选思路图、自检 |

- Agent **不得**用自身长文顶替 DeepSeek 正文。
- 无 `DEEPSEEK_API_KEY` 或 API 失败时：**报错并请用户配置密钥**，禁止静默代写全文。
- 日历**图片正文仍由用户自填**；DeepSeek 只出周次文字要点与表头元数据建议。
- 调用约定与 JSON schema：`reference/deepseek-contract.md`；客户端：`scripts/deepseek_generate.py`。
- **默认模型**：`deepseek-v4-pro`（DeepSeek 当前最新旗舰；可用环境变量 `DEEPSEEK_MODEL` 覆盖，如 `deepseek-v4-flash`）。

## 何时使用

用户提到：珠科 / ZCST / 教学大纲 / 教学日历 / 教案 / 进度表 / 一键生成教学材料 / `skill_lessonplan4zcst`。

## 硬规则（必须遵守）

1. **格式铁律**：复制官方模版后**只填内容**，不改字体、边距、样式、表格结构；禁止另起炉灶排版。
2. **流水线不可跳步**：人培对齐 → DeepSeek 大纲 → Agent 写入大纲 → **停下问上课时间** → DeepSeek 周次 → Agent 写日历 → DeepSeek 教案 → Agent 写教案 →（可选）PPT/思路图增强。
3. **未确认「周几 + 第几节–第几节」不得生成教学日历或教案课次时间。**
4. **课次跟日历/进度表逐格**，不擅自合并周次（除非用户明确要求）。
5. **教案第 1–2 页**（封面 + 编写说明）：用户未要求则不改。
6. **教学日历中的图片内容由用户自行填写**；技能只建 xlsx 骨架与图位说明，不编造图片正文。
7. 人培：用户上传优先；否则用默认数科人培（见 `reference/defaults.md`）。
8. 交付：默认 `他人物品/…/教案大纲/<课名>/`，并在工作区留副本；完成后跑自检清单。

## 模版选择

| 课程类型 | 大纲模版 |
|---|---|
| 理论 + 实验 / 纯理论 | 附件3 理论教学大纲通用模板 |
| 纯实验 | 附件4 实验教学大纲通用模板 |

实验学时为空或 0 → 按纯理论用附件3（或遵用户指定）。路径见 `reference/defaults.md`。

## 三种输入模式（首步判定）

读用户上传后选一种（可用 `scripts/detect_mode.py` 辅助）：

### 模式 A — 已有大纲和/或进度表

1. 解析课名、学时、目标、章节/周次，组装为 DeepSeek 上下文（可要求其润色/对齐人培，但仍走 API）。
2. DeepSeek 输出大纲 JSON → Agent 复制模版并写入。
3. 保留进度信息供日历与教案（缺周次文字时再调 DeepSeek）。

### 模式 B — 无大纲/进度，有教材目录或目录图

1. 解读目录（含 OCR 截图）→ 写入上下文。
2. DeepSeek：按总学时/周数切章节与周次要点 → Agent 填大纲。

### 模式 C — 仅课名（可附课码/班级/学时截图）

1. 对照人培定位课程与目标口径；截图字段写入上下文。
2. DeepSeek 起草大纲 JSON → Agent 写入 → 门禁问时间 → DeepSeek 周次/教案。

## 强制步骤

### 1. 人培对齐

核对课名、学分、总学时/理论/实验、目标表述与人培一致；摘录相关段落供 DeepSeek。

### 2. DeepSeek 生成大纲 + Agent 写入

- 调用 `scripts/deepseek_generate.py --task syllabus`（或等价 HTTP），取得 schema 合规 JSON。
- 复制附件3或附件4到交付目录；**只填** DeepSeek 给出的文本与表格单元格。
- 学时合计必须自洽；字段顺序见 `reference/field-map.md`。

### 3. 交互门禁（必须停下）

向用户确认（可多条：理论/实验不同）：

- 周几
- 第几节–第几节
- 教室（若有）

未回复则停止，不得继续日历/教案。

### 4. DeepSeek 周次 + 教学日历（xlsx）

- 调用 `--task weeks`，取得各周「教学内容」等文字。
- 参照大模型样例生成**理论**日历；有实验则另生成**实验**日历。
- 填：课码、课名、班级、周数、学时、周次行、上课时间列、周次教学内容（来自 DeepSeek）。
- **图片列/插图位留空或仅占位说明**，正文由用户自填。

### 5. DeepSeek 教案 + Agent 写入

- 调用 `--task lessons`（可按课次分批），取得各课字段。
- 复制教案参考模版；**详略对齐**大模型教案样板结构（导入 / 精讲 / 演示 / 练习 / 小结，分时段）。
- 每一课次对应日历一格；工具与课程一致。
- 质量条：`reference/quality-bar.md`（用于检查 DeepSeek 输出是否够详，不够则带反馈再调一次 API，仍禁止 Agent 自写长文顶替）。

### 6. 可选增强

- 用户提供 PPT/讲义 → 映射到周次写入参考资料/过程（映射逻辑可由 Agent 做；新增长文仍优先 DeepSeek）。
- 可为当周**自绘思路图/框架图**；非必要不滥截图。

## 技术约定

- DeepSeek：OpenAI 兼容 `https://api.deepseek.com`；默认模型 `deepseek-v4-pro`；密钥 `DEEPSEEK_API_KEY`。
- Word：`win32com`（必要时先结束 WINWORD/WPS）；改前 `SaveAs` 副本。
- Excel：`openpyxl` 基于样例复制再填。
- 出现中文自动编号叠字时，对污染区 `ListFormat.RemoveNumbers()`，勿误伤其它节。
- 技能以 Agent 按本 SKILL 执行为主；`scripts/` 辅助检测与 DeepSeek 调用，不绑定单门课硬编码正文。

## 完成后自检

- [ ] 大纲/周次/教案正文来自 DeepSeek JSON，非 Agent 代写
- [ ] 大纲学时合计 = 理论 + 实验（与人培/用户数据一致）
- [ ] 日历周次与上课时间已写入且与用户确认一致
- [ ] 教案课次与日历一致；无模版占位符残留
- [ ] 未改模版版式；教案第 1–2 页未被擅自修改
- [ ] 日历图片位未伪造用户内容
