# 端到端示例（runbook）

## 示例 1 — 模式 C（仅课名 + 表头截图）

**用户：**

> 帮我生成珠科教学材料。课程：大模型全栈应用开发。  
> （附教学日历表头截图）

**截图已含（示例）：**

- 课程代码 B2023024  
- 任选课；大数据学院；数据 2401-06；理论课室六教 M209  
- 考查；总学时 32；理论 32；实验空；周数 16；人数 60  

**Agent：**

1. 判定模式 C；读默认人培，定位该课学分学时与目标口径。  
2. 组装上下文 → `deepseek_generate.py --task syllabus`（模型默认 `deepseek-v4-pro`）→ 复制附件3，**只写入** DeepSeek JSON。  
3. **停下询问**：理论课周几、第几节–第几节（教室可确认 M209）。  
4. 用户回复后：`--task weeks` → 复制理论日历 xlsx，写入元数据与周次教学内容；**图片列留空**。  
5. `--task lessons` → 按日历写入教案；详略按 quality-bar 校验（不够则再调 DeepSeek，禁止 Agent 代写长文）；不改模版第 1–2 页。  
6. 自检学时与课次一致后交付路径。无 API Key 则在步骤 2 报错停止。

## 示例 2 — 模式 A（已有大纲 + 进度）

**用户：**

> 已有 Python 大纲和进度表，生成教案；时间：周二 5–6 节、周四 7–8 节。

**Agent：**

1. 模式 A；解析大纲/进度周次为 DeepSeek 上下文。  
2. 若大纲已是模版成品可跳过重填，或仅校验学时；缺周次/教案长文仍调 DeepSeek。  
3. 时间已给 → `--task weeks`（若需）→ 日历骨架 → `--task lessons` 按格写入。  
4. 课次不擅自合并。

## 示例 3 — 模式 B（教材目录图）

**用户：**

> 没有大纲，这是教材目录截图，总学时 48（理论 32+实验 16），帮我出大纲和日历。

**Agent：**

1. 模式 B；OCR/解读目录写入上下文 → DeepSeek `syllabus`（含周次切分）。  
2. Agent 写入附件3（含实验项目）。  
3. 问上课时间 → DeepSeek `weeks` → 理论+实验日历骨架 → DeepSeek `lessons` → 教案。

## 示例 4 — 带 PPT 增强

**用户：**

> 第 5–8 周用这个 PPT，适当配思路图。

**Agent：**

在已有教案上，将 PPT 挂到对应周「参考资料」；为理论周生成流程图插入过程设计；不改封面页。
